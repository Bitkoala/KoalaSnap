KoalaSnap 详细功能介绍与使用指南 Detailed features and usage guide for KoalaSnap

📸 功能特性

1. 可见区域截图

快速截取当前屏幕可见内容。适合需要快速分享当前看到的信息时使用。

  • 一键操作，即时保存
  • 快捷键：Ctrl+Shift+S (Mac: Cmd+Shift+S)

2. 整页滚动截图

自动滚动并拼接完整页面，完美支持长文章和长网页。

  • 智能识别页面高度
  • 自动处理固定定位元素（如导航栏）
  • 自动拼接成长图

3. 区域选择截图

自由选择截图区域，精确控制截图范围。

  • 可视化选择框
  • 鼠标拖拽调整大小
  • 支持 ESC 键取消操作

🚀 使用指南

方式一：点击扩展图标

  1. 点击浏览器工具栏的扩展图标
  2. 在弹出窗口中选择截图模式（可见区域、整页、区域选择）
  3. 等待截图完成并自动保存

方式二：使用快捷键

  • 按 Ctrl+Shift+S (Mac: Cmd+Shift+S)
  • 自动执行可见区域截图，无需打开菜单

截图保存位置

截图会自动保存到浏览器的默认下载目录，文件名格式：

  • screenshot_[时间戳].png - 可见区域截图
  • screenshot_full_[时间戳].png - 整页截图
  • screenshot_area_[时间戳].png - 区域截图

⚠️ 常见问题

1. 某些页面无法截图？

Chrome 内部页面（如 chrome://）和 Chrome Web Store 页面出于安全限制无法使用截图扩展。请在普通网页上试用。

2. 整页截图不完整？

对于无限加载的动态页面，整页截图可能无法截取所有内容。建议等待页面加载完成后再进行截图。

📸 Features

1. Visible Area

Quickly capture the currently visible content of the screen. Perfect for quick sharing.

  • One-click operation, instant save
  • Shortcut: Ctrl+Shift+S (Mac: Cmd+Shift+S)

2. Full Page

Automatically scroll and stitch the full page. Perfect for long articles and webpages.

  • Smart height detection
  • Handles fixed elements (like headers) automatically
  • Stitches into a thorough long image

3. Selected Area

Freely select the capture area with precise control.

  • Visual selection box
  • Drag to resize
  • Press ESC to cancel

🚀 Usage Guide

Method 1: Click Extension Icon

  1. Click the extension icon in the toolbar
  2. Select capture mode (Visible, Full Page, or Area) from the popup
  3. Wait for the capture to finish and save automatically

Method 2: Use Shortcut

  • Press Ctrl+Shift+S (Mac: Cmd+Shift+S)
  • Automatically triggers Visible Area capture

Save Location

Screenshots are automatically saved to your browser's default download directory. Filename formats:

  • screenshot_[timestamp].png - Visible Area
  • screenshot_full_[timestamp].png - Full Page
  • screenshot_area_[timestamp].png - Area Selection

⚠️ FAQ

1. Cannot capture on some pages?

Chrome internal pages (like chrome://) and the Chrome Web Store are restricted for security reasons. Please try on normal webpages.

2. Full page capture incomplete?

For infinitely scrolling dynamic pages, full page capture might not get everything. Please ensure the page is fully loaded before capturing.
