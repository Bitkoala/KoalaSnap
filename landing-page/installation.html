安装指南 Installation

KoalaSnap 从入门到精通 Getting started with KoalaSnap

?? 安装前准备

确保你已经完成以下准备：

  • ? Chrome 浏览器（版本 88 或更高）
  • ? 下载或克隆了本项目

应用商店安装 (推荐)

Chrome Web Store Edge Add-ons

?? 开发者模式安装 (离线使用)

步骤 1: 打开扩展管理页面

在 Chrome 浏览器地址栏输入：chrome://extensions/

或者通过菜单打开：点击浏览器右上角的 三个点 菜单 → 选择 更多工具 → 扩展程序。

步骤 2: 开启开发者模式

在扩展管理页面的右上角，找到并开启 「开发者模式」 开关。

步骤 3: 加载扩展

  1. 点击页面左上角的 「加载已解压的扩展程序」 按钮。
  2. 在弹出的文件选择对话框中，导航到本项目的根目录。
  3. 选择该文件夹并点击 「选择文件夹」。

步骤 4: 验证安装

安装成功后，你会看到：

  • ? 扩展列表中出现 「KoalaSnap - 考拉易截」
  • ? 浏览器工具栏出现蓝色相机图标
  • ? 扩展状态显示为 「已启用」

?? 快速测试

测试 1: 点击图标

点击工具栏的扩展图标，应看到包含三个截图模式的弹出窗口。

测试 2: 可见区域截图

打开任意网页，点击扩展图标，再点击「可见区域」按钮。检查下载文件夹是否有 PNG 截图。

测试 3: 快捷键

按 Ctrl+Shift+S (Mac: Cmd+Shift+S) 应自动截图。

?? 常见问题

扩展图标不显示？

点击浏览器工具栏的 拼图图标，找到「KoalaSnap」并点击 图钉图标 固定。

?? Developer Mode Installation

Step 1: Open Extensions Page

Enter chrome://extensions/ in your browser address bar.

Or open via menu: Click the three dots in top right → Select More Tools → Extensions.

Step 2: Enable Developer Mode

Toggle the "Developer mode" switch in the top right corner of the extensions page.

Step 3: Load Extension

  1. Click the "Load unpacked" button in the top left.
  2. Navigate to the root directory of this project.
  3. Select the folder and click "Select Folder".

Step 4: Verify Installation

Upon success, you will see:

  • ? "KoalaSnap" in the extension list
  • ? Blue camera icon in the toolbar
  • ? Extension status as "Enabled"

?? Quick Test

Test 1: Click Icon

Click the extension icon. A popup with three capture modes should appear.

Test 2: Visible Area

Open any webpage, click the icon, then click "Visible Area". Check your downloads folder for a PNG.

Test 3: Shortcut

Press Ctrl+Shift+S (Mac: Cmd+Shift+S) to auto-capture.

?? FAQ

Icon not showing?

Click the puzzle icon in the toolbar, find "KoalaSnap", and click the pin icon.
