# KoalaSnap 隐私政策

**最后更新日期：2026年1月10日**

## 概述

KoalaSnap（"考拉易截"）是一款 Chrome 浏览器截图扩展。我们非常重视您的隐私，本隐私政策说明了我们如何处理您的信息。

## 信息收集

**KoalaSnap 不收集、存储或传输任何个人信息。**

### 我们不收集的信息：
- ❌ 个人身份信息
- ❌ 浏览历史
- ❌ 网站内容
- ❌ 截图内容
- ❌ 使用统计数据
- ❌ 任何其他用户数据

## 权限说明

KoalaSnap 请求以下权限，仅用于提供核心截图功能：

### 1. `activeTab` - 访问当前标签页
**用途：** 截取当前网页的可见内容
**说明：** 仅在您主动触发截图时访问，不会在后台读取或记录任何内容

### 2. `scripting` - 脚本注入
**用途：** 
- 实现整页滚动截图功能（控制页面滚动）
- 实现区域选择功能（显示选择框 UI）

**说明：** 注入的脚本仅在您主动使用相应功能时运行，执行完毕后立即清理

### 3. `downloads` - 下载文件
**用途：** 将截图保存到您的本地下载文件夹
**说明：** 所有截图文件仅保存在您的本地计算机，不会上传到任何服务器

## 数据处理

### 本地处理
- ✅ 所有截图处理完全在您的浏览器本地完成
- ✅ 使用 Canvas API 在客户端拼接和裁剪图片
- ✅ 不涉及任何服务器通信

### 数据存储
- ✅ 截图文件仅保存在您的本地下载文件夹
- ✅ 扩展不创建任何本地数据库或缓存
- ✅ 不使用 Cookie 或本地存储

### 数据传输
- ✅ **零数据传输** - KoalaSnap 不与任何外部服务器通信
- ✅ 不包含任何分析或追踪代码
- ✅ 不加载任何第三方脚本

## 第三方服务

**KoalaSnap 不使用任何第三方服务**，包括但不限于：
- 分析服务（如 Google Analytics）
- 广告服务
- 云存储服务
- 任何其他外部 API

## 开源透明

KoalaSnap 的源代码可供审查，您可以验证：
- 没有数据收集代码
- 没有网络请求
- 没有追踪或分析

## 儿童隐私

KoalaSnap 不针对 13 岁以下儿童，也不会故意收集儿童的任何信息。

# Privacy Policy (English)

**Last Updated: January 10, 2026**

## Overview

KoalaSnap is a Chrome browser screenshot extension. We take your privacy seriously, and this privacy policy explains how we handle your information.

## Information Collection

**KoalaSnap does NOT collect, store, or transmit any personal information.**

### What We Don't Collect:
- ❌ Personal identification information
- ❌ Browsing history
- ❌ Website content
- ❌ Screenshot content
- ❌ Usage statistics
- ❌ Any other user data

## Permissions Explanation

KoalaSnap requests the following permissions solely to provide core screenshot functionality:

### 1. `activeTab` - Access Current Tab
**Purpose:** Capture visible content of the current webpage
**Note:** Only accessed when you actively trigger a screenshot, no background reading or recording

### 2. `scripting` - Script Injection
**Purpose:** 
- Enable full-page scrolling screenshots (control page scrolling)
- Enable area selection (display selection UI)

**Note:** Injected scripts only run when you actively use the respective features and are cleaned up immediately after execution

### 3. `downloads` - Download Files
**Purpose:** Save screenshots to your local Downloads folder
**Note:** All screenshot files are saved only on your local computer, never uploaded to any server

## Data Processing

### Local Processing
- ✅ All screenshot processing is done entirely locally in your browser
- ✅ Uses Canvas API for client-side image stitching and cropping
- ✅ No server communication involved

### Data Storage
- ✅ Screenshot files are only saved in your local Downloads folder
- ✅ Extension does not create any local database or cache
- ✅ Does not use cookies or local storage

### Data Transmission
- ✅ **Zero data transmission** - KoalaSnap does not communicate with any external servers
- ✅ Contains no analytics or tracking code
- ✅ Loads no third-party scripts

## Third-Party Services

**KoalaSnap does not use any third-party services**, including but not limited to:
- Analytics services (e.g., Google Analytics)
- Advertising services
- Cloud storage services
- Any other external APIs

## Open Source Transparency

KoalaSnap's source code is available for review, where you can verify:
- No data collection code
- No network requests
- No tracking or analytics

## Children's Privacy

KoalaSnap is not directed at children under 13 and does not knowingly collect any information from children.

## Privacy Policy Changes

If we update this privacy policy, we will post the new version on this page and update the "Last Updated" date.

## Contact Us

If you have any questions about this privacy policy, please contact us:

- **Email:** support@bitekaola.com
- **Website:** https://bitekaola.com

## User Rights

You have the following rights:
- ✅ Uninstall the extension at any time
- ✅ Review the extension source code
- ✅ Control extension permissions

## Compliance Statement

KoalaSnap complies with:
- Chrome Web Store Developer Program Policies
- General Data Protection Regulation (GDPR) (where applicable)
- California Consumer Privacy Act (CCPA) (where applicable)
